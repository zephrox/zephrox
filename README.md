### 🌟 Featured Projects

#### 🤖 1. [CogniLink / hci-companion](https://github.com/zephrox) — *Affective Desktop Companion Robot*
- Designed a **Sense → Think → Act** cognitive pipeline using MediaPipe FaceMesh to track 468 3D facial landmarks and classify user affective states with a Random Forest model.
- Implemented an asymmetrical temporal hysteresis filter (**"Sticky Focus"** + 85% supermajority vote buffer) that eliminates **90% of behavioral jitter** (blinks/sneezes).
- Real-time posture interpolation streaming joint angles over serial to an Arduino Nano driving a 4/5-DOF physical robotic manipulator and WS2812B chromatic LED array.
- **Tech Stack:** `Python` `MediaPipe` `OpenCV` `Scikit-learn` `Arduino (C++)` `Serial Telemetry`

---

#### 📖 2. [Shohoj Lipi (সহজ লিপি)](https://github.com/zephrox) — *Bangla Text Accessibility & Simplification*
> *SciBlitz AI Challenge 2026 (IEEE CUET) — Education & Accessibility Track*
- AI-driven assistive reading platform transforming complex Bangla text into dyslexia-friendly reading experiences.
- Multi-stage pipeline: Rule-based composite readability scorer, fine-tuned `BanglaBERT` sentence-level routing, and `Gemini LLM` contextual simplification preserving factual semantics.
- Features accessible typography, TTS synthesis with in-browser fallback, syllable-boundary dots, diff highlighting, and statistical evaluation (BERTScore, CC-density delta).
- **Tech Stack:** `FastAPI` `React 18` `Vite` `Tailwind CSS` `BanglaBERT` `Google Gemini API` `bnlp-toolkit`

#### 🎯 3. [Chakrify](https://github.com/zephrox) — *AI Resume Analysis & Job Matching Engine*
- Full-stack career acceleration platform featuring automated CV parsing (PDF/DOCX) via Gemini AI.
- Computes intelligent job-fit match scores (0–100) with granular skill-gap analysis and generates tailored, ATS-friendly cover letters in real time.
- Integrated JWT authentication and user dashboard for bookmarking opportunities and tracking applications.
- **Tech Stack:** `React 18` `Vite` `FastAPI` `Google Gemini API` `SQLite` `JWT` `Vanilla CSS`

#### 🔍 4. [AI Content Detection: BERT vs. RoBERTa](https://github.com/zephrox) — *NLP Deep Learning Study*
- Comparative fine-tuning and benchmarking study on transformer architectures for classifying AI-generated vs. human-written text.
- Evaluated on the 6,000-sample balanced Human ChatGPT Comparison Corpus (**HC3**).
- **RoBERTa** achieved superior performance with **99.50% Accuracy** and **99.48% F1-Score** (98.96% precision / 100% recall).
- **Tech Stack:** `PyTorch` `Hugging Face Transformers` `Datasets` `Scikit-learn` `Google Colab (T4)`
